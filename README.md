# Recherche-en-lectro--nerg-tique
Objectif. Réaliser trois mini-études techniques, chacune fondée sur un modèle mathématique, des simulations et des résultats reproductibles, afin de construire un profil de jeune ingénieur capable de modéliser, analyser et interpréter des phénomènes liés aux systèmes électriques. Chaque étude aboutit à un rapport de 4 à 6 pages, à un dépôt de code
